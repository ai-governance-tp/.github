# AI Governance TP

Tímový projekt FEI STU Bratislava (2026/2027) v spolupráci s Alison Slovakia s.r.o.

**Inteligentný systém pre automatizované hodnotenie bezpečnosti a governance AI systémov** — prototyp, ktorý z dokumentácie o AI modeli vytvorí bezpečnostný a governance profil s dohľadateľnosťou každého zistenia k zdroju.
